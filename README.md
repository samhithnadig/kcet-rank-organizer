# KCET Cutoff Rank Organizer

A web-based tool to extract and sort KCET (Karnataka Common Entrance Test) cutoff ranks from official KEA PDFs.

## 🚀 Features
- **PDF Upload:** Directly upload the official KEA PDF.
- **Auto-Extraction:** Automatically finds tables across multiple pages.
- **Smart Sort:** Sort by any category (GM, SCG, 1G, etc.) in ascending order.
- **Clean Export:** Download the sorted list as a CSV file for Excel.
